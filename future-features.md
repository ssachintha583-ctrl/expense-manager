# Future Features

The following features could be added to the Expense Manager in future versions:

## 1. User Authentication
Allow users to create accounts, log in securely, and manage their own expenses.

## 2. Expense Categories
Allow users to organise expenses into categories such as Food, Transport, Shopping, Bills, and Entertainment.

## 3. Monthly Reports
Provide monthly summaries showing total spending and spending patterns.

## 4. Budget Management
Allow users to set monthly budgets and receive warnings when spending approaches or exceeds the budget.

## 5. Search and Filtering
Allow users to search and filter expenses by date, expense type, description, or cost.

## 6. Data Visualisation
Display expense information using charts and graphs to make spending patterns easier to understand.

## 7. Export Functionality
Allow users to export expense records and reports to formats such as CSV or PDF.

## 8. Mobile Support
Improve the interface for mobile devices so users can manage expenses conveniently from phones and tablets.
